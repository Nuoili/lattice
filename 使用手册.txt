Lattice  ／  一键把窗口摆成预设布局
==========================================

【最常用】
  双击 Lattice.exe   -> 立刻按方案1排好，窗口提到最前，底部弹提示告诉排好几个。
                        同时自动拉起常驻（托盘出现图标），不用再点任何 bat。

【不会弹黑窗口】
  exe 是控制台子系统程序，双击时 Windows 会给它开一个控制台；因为进程随后转成常驻
  一直不退出，那个黑窗口就会赖在屏幕上。现在启动时会判断：
      · 控制台是这次新建的（双击 / 启动文件夹拉起）-> 自己藏起来，不显示
      · 控制台是复用的（在 cmd 里跑）-> 保持原样，--list / --capture 的输出照常看
  想在双击时故意留着窗口看输出：Lattice.exe --console

【托盘图标】
  图案：左侧一大块（蓝） + 右侧上下两块（橙/绿），就是方案1的布局缩影；透明底，无深色底板，
  16px 下三个块仍是分离的（图标按 16/20/24/32/48 逐尺寸手绘，不是一张大图缩下来的）。
  悬停提示会带上当前生效的热键组合，例如「Lattice ｜ Ctrl+Alt+Shift+1~3 切方案」。
  右键菜单：方案 1/2/3（打勾是当前）、打开配置文件夹、退出 Lattice
  左键单击：直接应用方案1
  图标被 Windows 折叠进 ^ 溢出区时，拖到任务栏上就固定住了。
  explorer 重启后图标会自动补回来（已处理 TaskbarCreated）。

【热键（独占注册，不和系统抢）】
  默认  Ctrl+Alt+Shift+1 / 2 / 3
  说明：以前用 Ctrl+Alt+数字 会顺手把系统/其他软件的热键也触发（轮询只是"读键"，
        不独占）。现在改成 RegisterHotKey 系统级独占——注册成功后别人收不到这组键。
  如果这三组都被占用，会按顺序自动降级，并把实际键位写进 lattice.log：
        1) Ctrl+Alt+Shift+数字
        2) Win+Alt+数字
        3) Ctrl+Alt+数字（最后兜底，可能仍冲突）
  退出常驻：Ctrl+Alt+Shift+Q   或   托盘右键 → 退出 Lattice
  想知道当前用的是哪组键：看 D://Lattice//lattice.log 里的"热键已独占注册"一行。

【目录结构（别只拷 exe）】
  D://Lattice//
      Lattice.exe          ← 双击这个
      _internal\           ← 运行时依赖，必须跟 exe 待在一起
      lattice.json         ← 你的布局方案
      README.txt

  为什么是"一个目录"而不是"单个 exe"：
  单文件模式（onefile）每次运行都要把自身解压到 %TEMP%\_MEIxxxx，退出时再删；
  删不掉就会弹 "Failed to remove temporary directory"。那是 PyInstaller 的清理提示，
  不是 Lattice 排布出错。现在改成目录模式，不再解压、不再产生临时目录，这个报错就没了。
  副作用都是好的：启动快了一截，%TEMP% 也不会再堆 _MEI 垃圾。
  代价：exe 不能单独拷走，要连 _internal 一起。

【开机自启】
  已放入启动文件夹：Lattice-startup.bat -> Lattice.exe --daemon --quiet
  不想要就删掉 C://Users//<你>//AppData//Roaming//Microsoft//Windows//Start Menu\Programs\Startup\Lattice-startup.bat

【关于缝隙：默认全部 2px】
  窗口与屏幕边缘 2px，相邻窗口之间 2px。由方案的 margin / gap 控制：
      "margin": 2    窗口与屏幕（工作区）边缘的距离，px
      "gap": 2       相邻窗口之间的缝隙，px（两侧各让一半，缝宽正好 = gap）

  这 2px 指的是"两块看得见的实心内容之间"的距离，不是"窗口矩形之间"的距离。
  这一点很关键：每个程序自己带的边缘宽度都不一样 ——
      Chrome   7px  系统隐形拖拽边框 + DWM 阴影带（画在矩形内侧）
      MuMu     3px  自己的深色边框 + 阴影带
      WorkBuddy 0px Electron 无边框窗口，矩形边就是内容边
  照着"窗口矩形"排，Chrome 那一侧会凭空多出七八像素的缝，视觉上就"不一样宽"。

  所以 Lattice 每次排位会先量一遍每个窗口真正画内容的位置：
  把窗口自己渲染出来的像素（PrintWindow）和屏幕上的真实像素逐列比对 ——
  屏幕上有阴影压暗的地方一眼就能认出来，量完再据此把可见边精确对到目标上。
  这套量法对任何程序都成立，不用维护一张按 exe 名分的补偿表。

  两个容易量错的地方，已经处理掉了：
    · 阴影带 ≠ 内容。DWM 阴影画在窗口矩形内侧，和"应用自己画的实心黑"在像素上
      长得一样。分不开的后果：MuMu 被拉成细高条时画面两侧有黑边，那块黑会被误判成
      "透明边"白白让位，窗口矩形压到邻居身上，缝隙就变 0。判据改成
      「自渲染是黑 + 屏幕也是黑 = 实心内容」；同时以 DWM 的可见边界为下界，
      那条界之外的像素一律不算内容（阴影只会出现在那里）。
    · 窗口不会自己乱动。实测 Chrome / MuMu / WorkBuddy 摆好后 3 秒内 rect 不变，
      所以不需要反复校正；看到位置跑偏基本是两处代码同时排位（例如连按热键）。

  另外排完会顺手整理层叠顺序：靠左的窗口沉到最底、同一列里靠下的也沉下去。
  DWM 画的阴影会往窗口外面溢出（Chrome 5px、MuMu 12px），压在右邻身上就会
  把那条缝撑宽；让压在上层的那一侧盖住它，两侧的缝宽才是同一个数。

  实测（三窗口：Chrome / WorkBuddy / MuMu，gap=2，逐像素核对接缝）：
      方案1  水平 Chrome|WorkBuddy   2 列      垂直 WorkBuddy|MuMu  2 行
             水平 Chrome|MuMu        2 列
      方案3  水平 Chrome|WorkBuddy   2 列
             水平 WorkBuddy|MuMu     2 列
  三处缝隙的宽度都和配置的 gap 一致。

【什么软件都能排：process 里的 * 通配】
  每个格子先在 process 里按 exe 名找；末尾加 |* 就多了一条兜底 —
  列出来的程序一个都没开时，用桌面上"还没被占用"的窗口顶上，不会空着一个格子。

      "process": "chrome|msedge|*"    优先 chrome/edge，都没有就拿任意窗口
      "process": "WorkBuddy|*"        优先 WorkBuddy，没开就拿任意窗口
      "process": "*"                  完全不管是什么程序，按最近使用顺序填

  默认三套方案都带 |* 了，所以微信、钉钉、飞书、VS Code、游戏、播放器……
  只要在桌面上，都能进格子。只写程序名、不加 |* 则保持老行为：匹配不到就跳过。

  挑选顺序（重要）：
    1. 写明了程序的格子先抢 —— 不然"任意窗口"的格子会把指定窗口占掉；
    2. 剩下的格子再从剩余窗口里补，按 z 序（最近用过的优先），
       所以主位（最大那块）往往落在你当前正在用的程序上。

  想看"这一下会把谁放到哪"但不真的动窗口：
      Lattice.exe --dry -p 1        预演，只打印分配结果
      Lattice.exe --list            连每格期望的程序一起列出来

【改成你自己的布局】
  lattice.json 里每个区块：
      "rect": [左边%, 上边%, 宽%, 高%]    百分比，相对"工作区"（自动避开任务栏/顶栏/dock）
      "process": "chrome|msedge|*"        exe 名正则，多个用竖线；单独 * = 任意窗口兜底
      "title": ""                         可选，窗口标题正则，用来区分同一程序的多窗口
  改完存盘即生效，不用重新打包。

【不想手算百分比？让它自己量】
  1. 先把窗口手动拖成你想要的样子
  2. 双击 Lattice-capture.bat  -> 把当前布局的百分比追加成新方案
  3. 之后要用：命令行跑 Lattice.exe -p 4 ／ 或把新方案挪到 profiles 第一位

【命令行】
  Lattice.exe                应用方案1 + 拉起常驻
  Lattice.exe -p 2           应用方案2
  Lattice.exe --once         只排一次，不拉起常驻
  Lattice.exe --list         列出可见窗口 + 所有方案（含每格期望的程序）
  Lattice.exe --dry -p 2     预演：只报分配结果，不移动窗口
  Lattice.exe --capture      打印当前布局百分比
  Lattice.exe --capture --save   存成新方案
  Lattice.exe --daemon       只跑常驻（托盘 + 热键）
  Lattice.exe --console      控制台前台跑，方便看输出

【出问题先看日志】
  D://Lattice//lattice.log 记录了：每次摆位结果、托盘注册结果、热键用了哪组、
  每次热键命中、每 5 分钟一次心跳。程序本身不弹任何错误框（除非一个窗口都没匹配到）。

【命名由来】
  Lattice = 格构/网格骨架。每个窗口各归其格，一套格构管所有布局。
